Skyreach Amber Coast is an original browser flight game: take off from the Amber Coast runway, thread six glowing rings over fields, hills and shoreline, manage throttle, fuel and airspeed, then return for a gentle runway landing. It has chase and cockpit views, a full HUD with altitude, speed and heading, synthesised engine sound, scoring, pause and restart, and runs entirely offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Press Enter or click Start Flight. Use Shift and Ctrl for throttle, arrow keys or WASD to steer, hold the mouse to steer, C for cockpit view, P to pause, R to restart and M to mute. Reach takeoff speed, pull up gently, fly through each green ring in order, then land slow, level and on the runway.
